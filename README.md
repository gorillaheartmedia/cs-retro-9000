# CS Retro 9000

CS Retro 9000 is a standalone browser-based retro music workstation. It provides five tracks, a piano-roll editor, pattern sequencing, automation, effects, MIDI export, WAV rendering, project import/export, and computer-keyboard performance controls.

## Run locally

No build step or external packages are required. Open `index.html` in a modern browser, or serve this directory with any static web server.

## GitHub Pages

This repository is ready to publish directly from the `main` branch root with GitHub Pages.

## Repository scope

This repository contains only the independent CS Retro 9000 web application:

- `index.html`
- `styles.css`
- `app.js`

It intentionally excludes APKs, Android project files, decompiled resources, and third-party application assets.
